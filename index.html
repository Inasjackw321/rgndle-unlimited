        Set up sign-in

        Sign-in needs a Google OAuth client ID. Every “Sign in with…” button on the web works this way — the site owner registers an app with the provider first. Nothing secret is involved: a client ID is public, which is why this game needs no server.

        In Google Cloud → Credentials, choose Create credentials → OAuth client ID, and pick the Web application type.

        Playing against everyone

        Out of the box the leaderboard lives in your browser, so only you appear on it. A shared board needs somewhere to store scores. The code is already in this repo — deploy it and paste the URL below: 

        cd worker
npx wrangler kv namespace create GUSSLE
# paste the returned id into wrangler.toml
npx wrangler deploy

        Free tier is plenty. GOOGLE_CLIENT_ID in wrangler.toml must match the client ID above, or the Worker rejects every sign-in.

        Saved in this browser only. To turn sign-in on for everyone who visits, put the same values in js/config.js and redeploy.

        How to play

        1. Everyone gets the same nine-digit target today.
        2. Roll the digits one at a time, left to right.
        3. After each roll, keep it or spend one of your three re-rolls on that digit. Re-rolls do not come back until tomorrow.
        4. The closer each digit lands to the target, the more it scores.

        Digits wrap

        Distance is measured the short way round, so 9 and 0 are one apart, and the worst you can ever be is 5. That isn't decoration: without wrapping, a day whose target was 000000000 would be nearly twice as hard as one of 555555555, and days would stop being comparable.

        Spending re-rolls

        There are only three, and an unspent one is worth points at the end — so a mediocre digit early is usually worth keeping, while the same digit on the last lane is worth burning a re-roll on. Judging that is the whole game.

        Ranks are real

        Your rank is your position in a measured distribution, not an arbitrary threshold.
